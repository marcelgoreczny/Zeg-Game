# Zeg-Game
Tytuł : Gra przeglądarkowa - Labirynt.

Opis :Celem projektu jest stworzenie nowoczesnej, przeglądarkowej gry typu labirynt, w której gracz steruje postacią poruszającą się po planszy, zbiera przedmioty, unika zagrożeń oraz rozwiązuje zagadki na kolejnych, coraz trudniejszych etapach. Nasza gra bedzie oparta o języki HTML, CSS i JavaScript. W grze będą zawarte poziomy, przeciwnicy, postać gracza, pułapki i meta. Tekstury zostały przez nas stworzone w programach Pixil Art i GIMP. Postać będzie interaktywnie przyjmowała podczas gry punkty zycia, odjemowała punkty zycia po wejściu w pułapkę albo po bitwie z przeciwnikiem. Postać jest całkowicie sterowana przez gracza za pomocą klawiszy WASD. 

Czas realizacji : od 10.04.2026 do 08.06.2026.

Autorzy : Marcel Góreczny i Konrad Gawęda.
